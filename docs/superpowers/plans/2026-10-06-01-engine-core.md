# Engine Core Implementation Plan (Plan 1 of 10)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the industry-neutral install engine (`installer start / next / submit / verify / resume / report`) with atomic resumable state and a hash-chained audit trail, proven by a scripted operator, idempotency tests and kill-between-steps tests, with no agent, connector or model involved.

**Architecture:** A pure-ish engine (`src/core/engine.ts`) walks a solution's ordered steps and returns the next actionable step. It runs `auto` and first-time `verify` steps itself, persists state after every transition, and appends an audit line before each save. The CLI (`src/cli.ts`) is a thin JSON-in/JSON-out shell over the engine. Every state transition returns a new object; files are written atomically (temp file + rename).

**Tech Stack:** TypeScript (strict, ESM, NodeNext), Node ≥ 22 built-ins only at runtime (`node:fs/promises`, `node:crypto`, `node:util` `parseArgs`), Vitest for tests, `tsc` for builds. No runtime dependencies.

**Spec:** [`docs/superpowers/specs/2026-10-06-installer-design.md`](../specs/2026-10-06-installer-design.md), decisions in [`DECISIONS.md`](../../../DECISIONS.md). Roadmap: [`README.md`](README.md).

**Decision for review (D44):** TypeScript was chosen during planning. If overruled, the code in this plan must be rewritten in the chosen language; task boundaries stay the same.

## Global Constraints

- Node ≥ 22; TypeScript `strict: true`; ESM with `.js` import suffixes (NodeNext).
- Zero runtime dependencies in this plan; dev dependencies only: `typescript`, `vitest`, `@types/node`.
- R3: no step requires Allen's account, keys or tokens; the engine contains no hard-coded accounts or service URLs.
- R4: `secret` and `oauth` inputs are **never** accepted through `submit`, `--value`, chat or any CLI argument.
- R9 / D27: no industry vocabulary in engine source or fixtures (enforced by a test in Task 10).
- R2 / D17: every step idempotent; state written after every step transition with an atomic write + rename.
- D34: every file the engine writes is confined to `engine_home`; `engine_home` is created with mode `0700`.
- D23 / §11.8: audit is append-only, hash-chained, and stores a payload fingerprint, never the raw payload.
- User coding style: immutable updates (return new objects, never mutate inputs); functions < 50 lines; files < 400 lines; no `console.log` (the CLI writes with `process.stdout.write` / `process.stderr.write`).
- Exit codes: `0` OK · `1` internal error · `2` usage / input / engine-rule error · `3` corrupt state file.
- Spec field names are kept verbatim: `step_id`, `phase`, `type`, `title`, `why`, `instructions`, `input.kind`, `blocking`, `est_minutes`, `resume`.

## Review Focus

1. **Corrupted or hand-edited `install-state.json`** — the CLI must stop with exit `3` and a clear message, and must never overwrite or "repair" the file. Test: Task 2 (unit), Task 8 (CLI).
2. **`submit` or `verify` for a step that is not the current one** (stale agent, wrong id, typo) — rejected with the current step named; state unchanged. Test: Task 6.
3. **Any command except `start` in a home with no install** — clear "run installer start" error, exit `2`, and no state file created as a side effect. Test: Task 8.
4. **`next` called repeatedly while a step is blocked, without `resume`** — returns the same blocked step every time; no attempt counter changes, no state writes. Test: Task 6.
5. **Host clock jumps backwards between steps** — the engine still progresses in solution order and records timestamps as given; nothing depends on timestamps being increasing. Test: Task 5.

```ts
import type { InputKind, StepInput } from "./types.js";

export class InputError extends Error {
  constructor(message: string) {
    super(message);
    this.name = "InputError";
  }
}

/** Kinds that are collected by the local browser page, never through submit (R4). */
export const AGENT_FORBIDDEN_KINDS: readonly InputKind[] = ["secret", "oauth"];

const TIME_PATTERN = /^([01]\d|2[0-3]):[0-5]\d$/;
const CRON_RANGES: readonly (readonly [number, number])[] = [
  [0, 59],
  [0, 23],
  [1, 31],
  [1, 12],
  [0, 7],
];

function validCronPart(part: string, min: number, max: number): boolean {
  const [base, step, ...rest] = part.split("/");
  if (rest.length > 0 || base === undefined || base === "") return false;
  if (step !== undefined && !/^[1-9]\d*$/.test(step)) return false;
  if (base === "*") return true;
  const match = /^(\d+)(?:-(\d+))?$/.exec(base);
  if (!match) return false;
  const low = Number(match[1]);
  const high = match[2] === undefined ? low : Number(match[2]);
  return low >= min && high <= max && low <= high;
}

export function isValidCron(expr: string): boolean {
  const fields = expr.trim().split(/\s+/);
  if (fields.length !== 5) return false;
  return fields.every((field, index) => {
    const range = CRON_RANGES[index];
    return range !== undefined && field.split(",").every((part) => validCronPart(part, range[0], range[1]));
  });
}

function requireString(value: unknown, what: string): string {
  if (typeof value !== "string" || value.trim() === "") throw new InputError(`${what} must be a non-empty string`);
  return value.trim();
}

function validateChoice(input: StepInput, value: unknown): unknown {
  const options = input.options ?? [];
  if (input.kind === "choice") {
    if (typeof value !== "string" || !options.includes(value)) {
      throw new InputError(`Answer must be one of: ${options.join(", ")}`);
    }
    return value;
  }
  if (!Array.isArray(value) || value.length === 0) throw new InputError("Select at least one option");
  if (!value.every((item) => typeof item === "string" && options.includes(item))) {
    throw new InputError(`Every selection must be one of: ${options.join(", ")}`);
  }
  return [...new Set(value as string[])];
}

export function validateInput(input: StepInput | undefined, value: unknown): unknown {
  if (!input) throw new InputError("This step takes no input");
  if (AGENT_FORBIDDEN_KINDS.includes(input.kind)) {
    throw new InputError(
      `'${input.kind}' values are never accepted through submit; they are collected by the local browser page`,
    );
  }
  switch (input.kind) {
    case "text":
    case "file":
      return requireString(value, "Answer");
    case "choice":
    case "multi_choice":
      return validateChoice(input, value);
    case "confirm":
      if (typeof value !== "boolean") throw new InputError("Answer must be true or false");
      return value;
    case "number":
      if (typeof value !== "number" || !Number.isFinite(value)) throw new InputError("Answer must be a number");
      return value;
    case "time":
      if (typeof value !== "string" || !TIME_PATTERN.test(value)) throw new InputError("Time must be HH:MM (24-hour)");
      return value;
    case "cron":
      if (typeof value !== "string" || !isValidCron(value)) throw new InputError("Schedule must be a 5-field cron expression");
      return value.trim();
    default:
      throw new InputError(`Unsupported input kind '${input.kind}'`);
  }
}
```

```ts
import { mkdir, readFile, rename, writeFile } from "node:fs/promises";
import { dirname, join } from "node:path";
import { crashPoint } from "./crash.js";
import { STEP_STATUSES, type InstallState } from "./types.js";

export const STATE_FILE = join("state", "install-state.json");

export class StateCorruptError extends Error {
  constructor(message: string) {
    super(message);
    this.name = "StateCorruptError";
  }
}

export function statePath(home: string): string {
  return join(home, STATE_FILE);
}

function isRecord(value: unknown): value is Record<string, unknown> {
  return typeof value === "object" && value !== null && !Array.isArray(value);
}

function isStepRecord(value: unknown): boolean {
  return (
    isRecord(value) &&
    typeof value.at === "string" &&
    (STEP_STATUSES as readonly unknown[]).includes(value.status) &&
    (value.attempts === undefined || typeof value.attempts === "number")
  );
}

export function isInstallState(value: unknown): value is InstallState {
  if (!isRecord(value) || value.schema !== 1 || typeof value.started_at !== "string") return false;
  const { solution, steps, audit_head: head } = value;
  if (!isRecord(solution) || !["ref", "id", "version"].every((key) => typeof solution[key] === "string")) return false;
  if (!isRecord(steps) || !Object.values(steps).every(isStepRecord)) return false;
  return head === undefined || (isRecord(head) && typeof head.seq === "number" && typeof head.hash === "string");
}

export async function loadState(home: string): Promise<InstallState | null> {
  let raw: string;
  try {
    raw = await readFile(statePath(home), "utf8");
  } catch (error) {
    if ((error as NodeJS.ErrnoException).code === "ENOENT") return null;
    throw error;
  }
  let parsed: unknown;
  try {
    parsed = JSON.parse(raw);
  } catch {
    throw new StateCorruptError(`${statePath(home)} is not valid JSON; it was not changed. Restore it or start in a new home.`);
  }
  if (!isInstallState(parsed)) {
    throw new StateCorruptError(`${statePath(home)} has an unexpected shape; it was not changed.`);
  }
  return parsed;
}

/** Atomic write: temp file in the same directory, then rename over the target. */
export async function saveState(home: string, state: InstallState): Promise<void> {
  const target = statePath(home);
  await mkdir(dirname(target), { recursive: true, mode: 0o700 });
  const temp = `${target}.${process.pid}.tmp`;
  await writeFile(temp, `${JSON.stringify(state, null, 2)}\n`, { encoding: "utf8", mode: 0o600 });
  crashPoint("state:before-rename");
  await rename(temp, target);
}
```

```ts
import { createHash } from "node:crypto";
import { appendFile, mkdir, readFile } from "node:fs/promises";
import { dirname, join } from "node:path";
import type { AuditHead } from "./types.js";

export const AUDIT_FILE = join("audit", "audit.jsonl");
export const GENESIS_HASH = "0".repeat(64);

export interface AuditEntry {
  readonly ts: string;
  readonly actor: "human" | "agent" | "engine";
  readonly event: string;
  readonly ref: string;
  readonly payload: unknown;
}

export interface AuditLine {
  readonly seq: number;
  readonly ts: string;
  readonly actor: string;
  readonly event: string;
  readonly ref: string;
  readonly payload_fingerprint: string;
  readonly prev_hash: string;
  readonly hash: string;
}

export type AuditCheck = { readonly ok: true; readonly lines: number } | { readonly ok: false; readonly line: number; readonly reason: string };

export function canonicalJson(value: unknown): string {
  if (value === null || typeof value !== "object") return JSON.stringify(value) ?? "null";
  if (Array.isArray(value)) return `[${value.map(canonicalJson).join(",")}]`;
  const entries = Object.entries(value as Record<string, unknown>)
    .filter(([, item]) => item !== undefined)
    .sort(([a], [b]) => (a < b ? -1 : a > b ? 1 : 0));
  return `{${entries.map(([key, item]) => `${JSON.stringify(key)}:${canonicalJson(item)}`).join(",")}}`;
}

const sha256 = (text: string): string => createHash("sha256").update(text).digest("hex");

function hashBody(body: Omit<AuditLine, "hash">): string {
  return sha256(body.prev_hash + canonicalJson(body));
}

async function readRows(home: string): Promise<string[]> {
  try {
    return (await readFile(join(home, AUDIT_FILE), "utf8")).split("\n").filter((row) => row.length > 0);
  } catch (error) {
    if ((error as NodeJS.ErrnoException).code === "ENOENT") return [];
    throw error;
  }
}

export async function appendAudit(home: string, entry: AuditEntry): Promise<AuditLine> {
  const rows = await readRows(home);
  const lastRow = rows.at(-1);
  const last = lastRow === undefined ? null : (JSON.parse(lastRow) as AuditLine);
  const body = {
    seq: (last?.seq ?? 0) + 1,
    ts: entry.ts,
    actor: entry.actor,
    event: entry.event,
    ref: entry.ref,
    payload_fingerprint: sha256(canonicalJson(entry.payload)),
    prev_hash: last?.hash ?? GENESIS_HASH,
  };
  const line: AuditLine = { ...body, hash: hashBody(body) };
  const file = join(home, AUDIT_FILE);
  await mkdir(dirname(file), { recursive: true, mode: 0o700 });
  await appendFile(file, `${JSON.stringify(line)}\n`, { encoding: "utf8", mode: 0o600 });
  return line;
}

export async function verifyAudit(home: string, head?: AuditHead): Promise<AuditCheck> {
  const rows = await readRows(home);
  const parsed: AuditLine[] = [];
  let previous = GENESIS_HASH;
  for (const [index, row] of rows.entries()) {
    const line = index + 1;
    let item: AuditLine;
    try {
      item = JSON.parse(row) as AuditLine;
    } catch {
      return { ok: false, line, reason: "not valid JSON" };
    }
    const { hash, ...body } = item;
    if (body.seq !== line) return { ok: false, line, reason: "sequence gap" };
    if (body.prev_hash !== previous) return { ok: false, line, reason: "previous-hash mismatch" };
    if (hashBody(body) !== hash) return { ok: false, line, reason: "hash mismatch" };
    parsed.push(item);
    previous = hash;
  }
  if (head && parsed[head.seq - 1]?.hash !== head.hash) {
    return { ok: false, line: head.seq, reason: "recorded head not found (lines removed?)" };
  }
  return { ok: true, lines: rows.length };
}
```

```ts
import { access, mkdir, writeFile } from "node:fs/promises";
import { dirname, resolve, sep } from "node:path";
import { InputError } from "./inputs.js";
import type { Action, Check } from "./types.js";

export interface CheckResult {
  readonly ok: boolean;
  readonly hint?: string;
}

type Args = Readonly<Record<string, unknown>>;

/** Every file the engine touches must stay inside engine_home (D34). */
export function resolveInHome(home: string, relative: string): string {
  const root = resolve(home);
  const target = resolve(root, relative);
  if (target === root || !target.startsWith(root + sep)) {
    throw new InputError(`Path '${relative}' is outside the engine home`);
  }
  return target;
}

function stringArg(args: Args, key: string): string {
  const value = args[key];
  if (typeof value !== "string") throw new InputError(`Argument '${key}' must be a string`);
  return value;
}

const ACTIONS: Readonly<Record<string, (home: string, args: Args) => Promise<void>>> = {
  noop: async () => undefined,
  write_file: async (home, args) => {
    const target = resolveInHome(home, stringArg(args, "path"));
    await mkdir(dirname(target), { recursive: true, mode: 0o700 });
    await writeFile(target, typeof args.content === "string" ? args.content : "", { encoding: "utf8", mode: 0o600 });
  },
};

const CHECKS: Readonly<Record<string, (home: string, args: Args) => Promise<CheckResult>>> = {
  file_exists: async (home, args) => {
    const path = stringArg(args, "path");
    try {
      await access(resolveInHome(home, path));
      return { ok: true };
    } catch (error) {
      if (error instanceof InputError) throw error;
      return { ok: false, hint: typeof args.hint === "string" ? args.hint : `Expected ${path} to exist` };
    }
  },
};

export const KNOWN_ACTIONS: readonly string[] = Object.keys(ACTIONS);
export const KNOWN_CHECKS: readonly string[] = Object.keys(CHECKS);

export async function runAction(home: string, action: Action): Promise<void> {
  const run = ACTIONS[action.action];
  if (!run) throw new InputError(`Unknown action '${action.action}'`);
  await run(home, action.args ?? {});
}

export async function runCheck(home: string, check: Check): Promise<CheckResult> {
  const run = CHECKS[check.check];
  if (!run) throw new InputError(`Unknown check '${check.check}'`);
  return run(home, check.args ?? {});
}
```

```ts
import { readFile } from "node:fs/promises";
import { KNOWN_ACTIONS, KNOWN_CHECKS } from "./actions.js";
import { INPUT_KINDS, PHASES, STEP_TYPES, type Phase, type Solution, type StepDef, type StepInput, type StepType } from "./types.js";

export class SolutionError extends Error {
  constructor(message: string) {
    super(message);
    this.name = "SolutionError";
  }
}

type Raw = Record<string, unknown>;
const isRecord = (value: unknown): value is Raw => typeof value === "object" && value !== null && !Array.isArray(value);

function text(value: unknown, where: string): string {
  if (typeof value !== "string" || value.trim() === "") throw new SolutionError(`${where} must be a non-empty string`);
  return value;
}

function oneOf<T extends string>(value: unknown, allowed: readonly T[], where: string): T {
  if (!(allowed as readonly unknown[]).includes(value)) throw new SolutionError(`${where} must be one of ${allowed.join(", ")}`);
  return value as T;
}

function parseInput(value: unknown, where: string): StepInput | undefined {
  if (value === undefined) return undefined;
  if (!isRecord(value)) throw new SolutionError(`${where} must be an object`);
  const kind = oneOf(value.kind, INPUT_KINDS, `${where}.kind`);
  const options = value.options;
  if ((kind === "choice" || kind === "multi_choice") && (!Array.isArray(options) || options.length === 0 || !options.every((o) => typeof o === "string"))) {
    throw new SolutionError(`${where}.options must list the choices`);
  }
  return { kind, ...(Array.isArray(options) ? { options: options as string[] } : {}), ...(typeof value.provider === "string" ? { provider: value.provider } : {}) };
}

function named(value: unknown, key: "action" | "check", known: readonly string[], where: string): { name: string; args: Raw } {
  if (!isRecord(value)) throw new SolutionError(`${where} must be an object`);
  const name = oneOf(value[key], known, `${where}.${key}`);
  return { name, args: isRecord(value.args) ? value.args : {} };
}

function checkTypeRules(step: StepDef, where: string): void {
  if (step.type === "ask" && !step.input) throw new SolutionError(`${where}: ask steps need an input`);
  if (step.type === "auto" && !step.auto) throw new SolutionError(`${where}: auto steps need an auto action`);
  if (step.type === "verify" && !step.verify) throw new SolutionError(`${where}: verify steps need a check`);
  if (step.type === "agent_action" && (!step.intent || !step.verify)) throw new SolutionError(`${where}: agent_action steps need an intent and a check`);
}

function parseStep(value: unknown, index: number): StepDef {
  const where = `steps[${index}]`;
  if (!isRecord(value)) throw new SolutionError(`${where} must be an object`);
  if (typeof value.blocking !== "boolean") throw new SolutionError(`${where}.blocking must be true or false`);
  const auto = value.auto === undefined ? undefined : named(value.auto, "action", KNOWN_ACTIONS, `${where}.auto`);
  const verify = value.verify === undefined ? undefined : named(value.verify, "check", KNOWN_CHECKS, `${where}.verify`);
  const input = parseInput(value.input, `${where}.input`);
  const step: StepDef = {
    step_id: text(value.step_id, `${where}.step_id`),
    phase: oneOf<Phase>(value.phase, PHASES, `${where}.phase`),
    type: oneOf<StepType>(value.type, STEP_TYPES, `${where}.type`),
    title: text(value.title, `${where}.title`),
    why: text(value.why, `${where}.why`),
    blocking: value.blocking,
    ...(Array.isArray(value.instructions) ? { instructions: value.instructions.map((line) => text(line, `${where}.instructions`)) } : {}),
    ...(input ? { input } : {}),
    ...(typeof value.est_minutes === "number" ? { est_minutes: value.est_minutes } : {}),
    ...(typeof value.intent === "string" && value.intent.trim() !== "" ? { intent: value.intent } : {}),
    ...(auto ? { auto: { action: auto.name, args: auto.args } } : {}),
    ...(verify ? { verify: { check: verify.name, args: verify.args } } : {}),
  };
  checkTypeRules(step, where);
  return step;
}

export function parseSolution(raw: unknown): Solution {
  if (!isRecord(raw)) throw new SolutionError("Solution must be a JSON object");
  const id = text(raw.id, "id");
  const version = text(raw.version, "version");
  if (!Array.isArray(raw.steps) || raw.steps.length === 0) throw new SolutionError("steps must be a non-empty list");
  const steps = raw.steps.map(parseStep);
  steps.reduce((seen, step) => {
    if (seen.has(step.step_id)) throw new SolutionError(`Duplicate step id '${step.step_id}'`);
    return new Set([...seen, step.step_id]);
  }, new Set<string>());
  steps.reduce((previous, step) => {
    const index = PHASES.indexOf(step.phase);
    if (index < previous) throw new SolutionError(`Step '${step.step_id}' is in phase ${step.phase}, earlier than the previous step`);
    return index;
  }, 0);
  return { id, version, steps };
}

export async function loadSolution(ref: string): Promise<Solution> {
  if (!ref.startsWith("file:")) throw new SolutionError(`Unsupported solution reference '${ref}': only file:<path> is supported in this version`);
  const path = ref.slice("file:".length);
  let raw: string;
  try {
    raw = await readFile(path, "utf8");
  } catch {
    throw new SolutionError(`Cannot read solution file '${path}'`);
  }
  let json: unknown;
  try {
    json = JSON.parse(raw);
  } catch {
    throw new SolutionError(`Solution file '${path}' is not valid JSON`);
  }
  return parseSolution(json);
}
```

```ts
import { runAction, runCheck } from "./actions.js";
import { crashPoint } from "./crash.js";
import type { AuditHead, InstallState, Solution, StepDef, StepRecord, StepStatus } from "./types.js";

export const MAX_VERIFY_ATTEMPTS = 3;
export const RESUME_HINT = "installer resume";

export class EngineError extends Error {
  constructor(message: string) {
    super(message);
    this.name = "EngineError";
  }
}

export type Actor = "human" | "agent" | "engine";

export interface AuditEvent {
  readonly actor: Actor;
  readonly event: string;
  readonly ref: string;
  readonly payload: unknown;
}

export interface EngineDeps {
  readonly home: string;
  readonly solution: Solution;
  readonly now: () => string;
  readonly save: (state: InstallState) => Promise<void>;
  readonly audit: (event: AuditEvent) => Promise<AuditHead>;
}

export interface StepView {
  readonly step: StepDef;
  readonly status: StepStatus;
  readonly attempts: number;
  readonly hint?: string;
  readonly resume: string;
}

export type NextResult =
  | { readonly status: "step"; readonly view: StepView }
  | { readonly status: "blocked"; readonly view: StepView }
  | { readonly status: "complete" };

export interface Advanced {
  readonly state: InstallState;
  readonly result: NextResult;
}

export type VerifyResult =
  | { readonly status: "passed" }
  | { readonly status: "failed"; readonly hint: string; readonly retry: true }
  | { readonly status: "blocked"; readonly hint: string; readonly retry: false };

const SETTLED: readonly StepStatus[] = ["done", "skipped"];

export function recordOf(state: InstallState, stepId: string): StepRecord | undefined {
  return state.steps[stepId];
}

export function initialState(ref: string, solution: Solution, now: string): InstallState {
  return { schema: 1, solution: { ref, id: solution.id, version: solution.version }, started_at: now, steps: {} };
}

/** First step that is not settled; non-blocking blocked steps are passed over. */
export function currentStep(solution: Solution, state: InstallState): StepDef | null {
  for (const step of solution.steps) {
    const record = recordOf(state, step.step_id);
    if (record && SETTLED.includes(record.status)) continue;
    if (record?.status === "blocked" && !step.blocking) continue;
    return step;
  }
  return null;
}

function viewOf(step: StepDef, record: StepRecord | undefined): StepView {
  return {
    step,
    status: record?.status ?? "pending",
    attempts: record?.attempts ?? 0,
    ...(record?.hint ? { hint: record.hint } : {}),
    resume: RESUME_HINT,
  };
}

/** Audit first, then save: a crash in between repeats an audit line but never loses one. */
export async function transition(deps: EngineDeps, state: InstallState, step: StepDef, record: StepRecord, actor: Actor): Promise<InstallState> {
  const head = await deps.audit({ actor, event: `step.${record.status}`, ref: step.step_id, payload: { status: record.status, attempts: record.attempts ?? 0 } });
  const next: InstallState = { ...state, steps: { ...state.steps, [step.step_id]: record }, audit_head: head };
  await deps.save(next);
  return next;
}

export async function runVerify(deps: EngineDeps, state: InstallState, step: StepDef, actor: Actor): Promise<{ state: InstallState; result: VerifyResult }> {
  if (!step.verify) throw new EngineError(`Step '${step.step_id}' has nothing to verify`);
  const check = await runCheck(deps.home, step.verify);
  if (check.ok) {
    return { state: await transition(deps, state, step, { status: "done", at: deps.now(), by: actor }, actor), result: { status: "passed" } };
  }
  const attempts = (recordOf(state, step.step_id)?.attempts ?? 0) + 1;
  const hint = check.hint ?? "Check failed";
  if (attempts >= MAX_VERIFY_ATTEMPTS) {
    const record: StepRecord = { status: "blocked", at: deps.now(), attempts, hint, reason: `check failed ${attempts} times` };
    return { state: await transition(deps, state, step, record, actor), result: { status: "blocked", hint, retry: false } };
  }
  const record: StepRecord = { status: "failed", at: deps.now(), attempts, hint };
  return { state: await transition(deps, state, step, record, actor), result: { status: "failed", hint, retry: true } };
}

/** Runs engine-owned steps until a human/agent step, a blocking problem, or completion. */
export async function advance(deps: EngineDeps, state: InstallState): Promise<Advanced> {
  let current = state;
  for (;;) {
    const step = currentStep(deps.solution, current);
    if (!step) return { state: current, result: { status: "complete" } };
    const record = recordOf(current, step.step_id);
    if (record?.status === "blocked") return { state: current, result: { status: "blocked", view: viewOf(step, record) } };
    if (step.type === "auto" && step.auto) {
      await runAction(deps.home, step.auto);
      crashPoint("engine:after-action");
      current = await transition(deps, current, step, { status: "done", at: deps.now(), by: "engine" }, "engine");
      continue;
    }
    if (step.type === "verify" && (record === undefined || record.status === "pending")) {
      current = (await runVerify(deps, current, step, "engine")).state;
      continue;
    }
    return { state: current, result: { status: "step", view: viewOf(step, record) } };
  }
}

export async function start(deps: EngineDeps, existing: InstallState | null, ref: string): Promise<Advanced> {
  if (existing) {
    const same = existing.solution.ref === ref && existing.solution.id === deps.solution.id && existing.solution.version === deps.solution.version;
    if (!same) throw new EngineError(`This home already has an install of '${existing.solution.id}' from ${existing.solution.ref}; use a different --home`);
    return advance(deps, existing);
  }
  const head = await deps.audit({ actor: "human", event: "install.started", ref, payload: { id: deps.solution.id, version: deps.solution.version } });
  const fresh: InstallState = { ...initialState(ref, deps.solution, deps.now()), audit_head: head };
  await deps.save(fresh);
  return advance(deps, fresh);
}
```

```ts
  const current = currentStep(deps.solution, state);
  if (!current || current.step_id !== stepId) {
    const where = current ? `; current step is '${current.step_id}'` : "; the install has no pending step";
    throw new EngineError(`Step '${stepId}' is not the current step${where}`);
  }
  if (recordOf(state, stepId)?.status === "blocked") throw new EngineError(`Step '${stepId}' is blocked; run '${RESUME_HINT}' first`);
  return step;
}

function submittedRecord(deps: EngineDeps, step: StepDef, payload: SubmitPayload): StepRecord {
  if (step.type === "ask") {
    if (payload.kind !== "value") throw new EngineError(`Step '${step.step_id}' needs an answer: use --value`);
    return { status: "done", at: deps.now(), by: "human", value: validateInput(step.input, payload.value) };
  }
  if (step.type === "human_action") {
    if (step.input && (step.input.kind === "secret" || step.input.kind === "oauth")) {
      throw new EngineError(`Step '${step.step_id}' is completed by the local browser page, never through submit`);
    }
    if (step.verify) throw new EngineError(`Step '${step.step_id}' is confirmed by a check: run 'installer verify ${step.step_id}'`);
    if (payload.kind !== "done") throw new EngineError(`Step '${step.step_id}' takes no value: use --done`);
    return { status: "done", at: deps.now(), by: "human" };
  }
  const hint = step.type === "agent_action" ? `: perform the intent, then run 'installer verify ${step.step_id}'` : "";
  throw new EngineError(`Step '${step.step_id}' (${step.type}) cannot be submitted${hint}`);
}

export async function submit(deps: EngineDeps, state: InstallState, stepId: string, payload: SubmitPayload): Promise<Advanced> {
  const settled = (await advance(deps, state)).state;
  const step = requireCurrent(deps, settled, stepId);
  const record = submittedRecord(deps, step, payload);
  return advance(deps, await transition(deps, settled, step, record, "human"));
}

export async function verifyStep(deps: EngineDeps, state: InstallState, stepId: string): Promise<Verified> {
  const settled = (await advance(deps, state)).state;
  const step = requireCurrent(deps, settled, stepId);
  if (!step.verify) throw new EngineError(`Step '${stepId}' has no check; use 'installer submit'`);
  const actor: Actor = step.type === "agent_action" ? "agent" : step.type === "human_action" ? "human" : "engine";
  const verified = await runVerify(deps, settled, step, actor);
  const { state: final, result: next } = await advance(deps, verified.state);
  return { state: final, result: verified.result, next };
}

/** Gives every blocked step a fresh set of attempts, then continues. */
export async function resume(deps: EngineDeps, state: InstallState): Promise<Advanced> {
  let current = state;
  for (const step of deps.solution.steps) {
    if (recordOf(current, step.step_id)?.status === "blocked") {
      current = await transition(deps, current, step, { status: "pending", at: deps.now(), attempts: 0 }, "human");
    }
  }
  return advance(deps, current);
}
```

```ts
import { RESUME_HINT, currentStep } from "./engine.js";
import type { InstallState, Phase, Solution, StepDef, StepRecord } from "./types.js";

export type Overall = "ready" | "ready_with_limits" | "blocked" | "in_progress";

export interface ReportItem {
  readonly step_id: string;
  readonly title: string;
  readonly detail: string;
}

export interface Report {
  readonly overall: Overall;
  readonly solution: string;
  readonly phase: Phase | null;
  readonly done: number;
  readonly total: number;
  readonly working: readonly ReportItem[];
  readonly limited: readonly ReportItem[];
  readonly needs_you: readonly ReportItem[];
}

const HEADLINE: Readonly<Record<Overall, string>> = {
  ready: "✅ READY",
  ready_with_limits: "⚠️ READY WITH LIMITS",
  blocked: "⛔ BLOCKED",
  in_progress: "⏳ IN PROGRESS",
};

const item = (step: StepDef, detail: string): ReportItem => ({ step_id: step.step_id, title: step.title, detail });
const unresolved = (record: StepRecord | undefined): boolean => record?.status === "blocked" || record?.status === "skipped";

export function buildReport(solution: Solution, state: InstallState): Report {
  const rows = solution.steps.map((step) => ({ step, record: state.steps[step.step_id] }));
  const working = rows.filter(({ record }) => record?.status === "done").map(({ step }) => item(step, "done"));
  const limited = rows
    .filter(({ step, record }) => !step.blocking && unresolved(record))
    .map(({ step, record }) => item(step, record?.hint ?? record?.reason ?? record?.status ?? ""));
  const hardBlocked = rows.filter(({ step, record }) => step.blocking && record?.status === "blocked");
  const current = currentStep(solution, state);
  const waitingOnHuman = current && (current.type === "ask" || current.type === "human_action") && !hardBlocked.some(({ step }) => step.step_id === current.step_id);
  const needs_you = [
    ...hardBlocked.map(({ step, record }) => item(step, `${record?.hint ?? "Blocked"} → then run '${RESUME_HINT}'`)),
    ...(waitingOnHuman ? [item(current, current.instructions?.join(" ") ?? current.why)] : []),
  ];
  const overall: Overall = hardBlocked.length > 0 ? "blocked" : current ? "in_progress" : limited.length > 0 ? "ready_with_limits" : "ready";
  return { overall, solution: `${solution.id}@${solution.version}`, phase: current?.phase ?? null, done: working.length, total: solution.steps.length, working, limited, needs_you };
}

export function renderReport(report: Report): string {
  const lines = [`${HEADLINE[report.overall]}  (${report.done} of ${report.total} steps done) · ${report.solution}`];
  if (report.working.length > 0) lines.push(`✅ Working    ${report.working.map((entry) => entry.title).join(" · ")}`);
  report.limited.forEach((entry, index) => lines.push(`${index === 0 ? "⚠️ Limited   " : "             "}${entry.title} — ${entry.detail}`));
  report.needs_you.forEach((entry, index) => lines.push(`${index === 0 ? "⛔ Needs you " : "             "}${index + 1}. ${entry.title} — ${entry.detail}`));
  return lines.join("\n");
}
```

```ts
export interface CliResult {
  readonly code: number | null;
  readonly signal: NodeJS.Signals | null;
  readonly stdout: string;
  readonly stderr: string;
  readonly json: unknown;

function lastJson(text: string): unknown {
  const line = text.trim().split("\n").at(-1);
  if (!line) return null;
  try {
    return JSON.parse(line);
  } catch {
    return null;
  }
}

export function runCli(args: readonly string[], options: { home: string; env?: Record<string, string> }): CliResult {

    encoding: "utf8",
    env: { ...process.env, ...options.env },
  });
  return { code: result.status, signal: result.signal, stdout: result.stdout, stderr: result.stderr, json: lastJson(result.stdout) ?? lastJson(result.stderr) };
}
```

```ts
#!/usr/bin/env node
import { chmod, mkdir } from "node:fs/promises";
import { homedir } from "node:os";
import { join, resolve } from "node:path";
import { parseArgs } from "node:util";
import { appendAudit } from "./core/audit.js";
import { EngineError, advance, resume, start, submit, verifyStep, type EngineDeps, type SubmitPayload } from "./core/engine.js";
import { InputError } from "./core/inputs.js";
import { buildReport, renderReport } from "./core/report.js";
import { SolutionError, loadSolution } from "./core/solution.js";
import { StateCorruptError, loadState, saveState } from "./core/state.js";
import type { InstallState, Solution } from "./core/types.js";

export const EXIT = { OK: 0, INTERNAL: 1, USAGE: 2, STATE_CORRUPT: 3 } as const;
const HOME_MODE = 0o700;
const COMMANDS = "start, next, submit, verify, resume, report";

class NoInstallError extends Error {
  constructor() {
    super("No install found in this home; run 'installer start --solution <ref>' first");
    this.name = "NoInstallError";
  }
}

interface Flags {
  readonly home?: string;
  readonly solution?: string;
  readonly value?: string;
  readonly done?: boolean;
  readonly json?: boolean;
}

function emit(stream: NodeJS.WriteStream, value: unknown): void {
  stream.write(`${typeof value === "string" ? value : JSON.stringify(value)}\n`);
}

function parse(argv: readonly string[]): { flags: Flags; positionals: string[] } {
  try {
    const { values, positionals } = parseArgs({
      args: [...argv],
      allowPositionals: true,
      options: { home: { type: "string" }, solution: { type: "string" }, value: { type: "string" }, done: { type: "boolean" }, json: { type: "boolean" } },
    });
    return { flags: values, positionals };
  } catch (error) {
    throw new InputError((error as Error).message);
  }
}

function depsFor(home: string, solution: Solution): EngineDeps {
  const now = (): string => new Date().toISOString();
  return {
    home,
    solution,
    now,
    save: (state) => saveState(home, state),
    audit: async (event) => {
      const line = await appendAudit(home, { ...event, ts: now() });
      return { seq: line.seq, hash: line.hash };
    },
  };
}

async function loadInstall(home: string): Promise<{ state: InstallState; deps: EngineDeps }> {
  const state = await loadState(home);
  if (!state) throw new NoInstallError();
  const solution = await loadSolution(state.solution.ref);
  if (solution.id !== state.solution.id || solution.version !== state.solution.version) {
    throw new EngineError(`Solution at ${state.solution.ref} is now ${solution.id}@${solution.version}; this install uses ${state.solution.id}@${state.solution.version}`);
  }
  return { state, deps: depsFor(home, solution) };
}

function submitPayload(flags: Flags): SubmitPayload {
  if (flags.done && flags.value !== undefined) throw new InputError("Use either --value or --done, not both");
  if (flags.done) return { kind: "done" };
  if (flags.value === undefined) throw new InputError("submit needs --value <json> or --done");
  try {
    return { kind: "value", value: JSON.parse(flags.value) as unknown };
  } catch {
    throw new InputError(`--value must be JSON, for text use quotes: --value '"yes"'`);
  }
}

function requireArg(arg: string | undefined, command: string): string {
  if (!arg) throw new InputError(`${command} needs a step id`);
  return arg;
}

async function startCommand(home: string, flags: Flags): Promise<unknown> {
  if (!flags.solution) throw new InputError("start needs --solution <ref>");
  const ref = flags.solution.startsWith("file:") ? `file:${resolve(flags.solution.slice("file:".length))}` : flags.solution;
  const solution = await loadSolution(ref);
  await mkdir(home, { recursive: true, mode: HOME_MODE });
  await chmod(home, HOME_MODE);
  return (await start(depsFor(home, solution), await loadState(home), ref)).result;
}

async function run(argv: readonly string[]): Promise<number> {
  const { flags, positionals } = parse(argv);
  const home = resolve(flags.home ?? process.env.INSTALLER_HOME ?? join(homedir(), ".installer"));
  const [command, arg] = positionals;
  if (command === "start") {
    emit(process.stdout, await startCommand(home, flags));
    return EXIT.OK;
  }
  if (!command || !["next", "submit", "verify", "resume", "report"].includes(command)) {
    throw new InputError(`Unknown command '${command ?? ""}'. Commands: ${COMMANDS}`);
  }
  const { state, deps } = await loadInstall(home);
  if (command === "next") emit(process.stdout, (await advance(deps, state)).result);
  if (command === "submit") emit(process.stdout, (await submit(deps, state, requireArg(arg, command), submitPayload(flags))).result);
  if (command === "verify") {
    const verified = await verifyStep(deps, state, requireArg(arg, command));
    emit(process.stdout, { ...verified.result, next: verified.next });
  }
  if (command === "resume") emit(process.stdout, (await resume(deps, state)).result);
  if (command === "report") {
    const report = buildReport(deps.solution, state);
    emit(process.stdout, flags.json ? report : renderReport(report));
  }
  return EXIT.OK;
}

function exitCodeFor(error: unknown): number {
  if (error instanceof StateCorruptError) return EXIT.STATE_CORRUPT;
  if (error instanceof InputError || error instanceof EngineError || error instanceof SolutionError || error instanceof NoInstallError) return EXIT.USAGE;
  return EXIT.INTERNAL;
}

run(process.argv.slice(2))
  .then((code) => {
    process.exitCode = code;
  })
  .catch((error: unknown) => {
    const code = exitCodeFor(error);
    const message = error instanceof Error ? error.message : String(error);
    emit(process.stderr, { error: code === EXIT.INTERNAL ? `Internal error: ${message}` : message, code });
    process.exitCode = code;
  });
```

```ts
interface StepJson {
  readonly status: string;
  readonly view?: { readonly step: { readonly step_id: string; readonly type: string } };
  readonly next?: StepJson;
}

const MAX_CALLS = 60;

const writeMarker = (path: string) => async (home: string): Promise<void> => {
  await mkdir(join(home, "config"), { recursive: true });
  await writeFile(join(home, path), "ok\n", "utf8");
};

export const FIXTURE_SCRIPT: OperatorScript = {
  answers: { "mode.shared-work": "yes", "mode.report-time": "09:00" },
  perform: { "brain.register": writeMarker("config/agent-marker.txt"), "channels.optional-extra": writeMarker("config/extra-channel.txt") },
};

export const GIVE_UP_SCRIPT: OperatorScript = { ...FIXTURE_SCRIPT, giveUp: ["channels.optional-extra"] };

/** A fake agent: follows the step protocol exactly as INSTALL.md tells a real agent to. */
export async function operate(options: { home: string; solutionRef: string; script: OperatorScript; crash?: CrashPlan }): Promise<OperatorRun> {
  const calls: CliResult[] = [];
  let crashed = 0;
  const call = (args: readonly string[]): CliResult => {
    const env = options.crash && calls.length === options.crash.atCall ? { INSTALLER_CRASH_AT: options.crash.point } : undefined;
    const result = runCli(args, { home: options.home, ...(env ? { env } : {}) });
    calls.push(result);
    return result;
  };
  const recover = (): CliResult => {
    const resumed = call(["resume"]);
    return resumed.code === 2 && resumed.stderr.includes("No install found") ? call(["start", "--solution", options.solutionRef]) : resumed;
  };
  const step = (args: readonly string[]): StepJson => {
    let result = call(args);
    if (result.signal === "SIGKILL") {
      crashed += 1;
      result = recover();
    }
    if (result.code !== 0) throw new Error(`installer ${args.join(" ")} failed: ${result.stderr}`);
    const json = result.json as StepJson;
    return json.next ?? json;
  };

  let current = step(["start", "--solution", options.solutionRef]);
  while (calls.length < MAX_CALLS) {
    if (current.status === "complete" || current.status === "blocked" || !current.view) return { final: current, calls, crashed };
    const { step_id: id, type } = current.view.step;
    if (type === "ask") {
      if (!(id in options.script.answers)) throw new Error(`No scripted answer for ${id}`);
      current = step(["submit", id, "--value", JSON.stringify(options.script.answers[id])]);
    } else if (type === "agent_action" || type === "human_action") {
      const perform = options.script.giveUp?.includes(id) ? undefined : options.script.perform[id];
      if (perform) await perform(options.home);
      current = perform || type === "agent_action" || options.script.giveUp?.includes(id) ? step(["verify", id]) : step(["submit", id, "--done"]);
    } else {
      current = step(["next"]);
    }
  }
  throw new Error(`Operator exceeded ${MAX_CALLS} calls`);
}
```

```ts
async function snapshot(home: string) {

  const steps = Object.fromEntries(
    Object.entries(state?.steps ?? {}).map(([id, record]) => [id, { status: record.status, value: record.value, attempts: record.attempts ?? 0 }]),
```
