# Local MCP Server + Approvals Implementation Plan (Plan 4 of 10)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give the host agent the installer's own tools over a local MCP server (and the same tools as `installer tool <name> '<json>'` when it has no MCP client), and make every tool at level L2 or L3 refuse to run until a person has approved that exact call: approval items with a mandatory `why`, levels derived by the engine with a compiled floor, single-use action-hash tokens, and the decisions approve / edit / reject / expire with the decision maker role.

**Architecture:** `src/core/levels.ts` derives a call's level from declared tool metadata, floor categories, field tags and client rules (never from the model). `src/core/numbered.ts` keeps one JSON file per item under the engine home, takes ids with a hard link and spends tokens with an exclusive create; `appendAudit` gains a lock file because the MCP server and the CLI now write at the same time. `src/core/approvals.ts` creates items, applies decisions and redeems tokens; `src/core/tools.ts` is the one gate both surfaces call (`invokeTool`), with a registry that Plans 5–6 extend; `memo.*` and `approvals.request | list | get` are the v1 tools. `installer approvals …` decides from a person's terminal only. `src/core/mcp-server.ts` is a hand-rolled newline-delimited JSON-RPC server behind `installer mcp-serve`, which an install step registers in the agent with the profile's `mcp_register` template.

**Tech Stack:** TypeScript (strict, ESM, NodeNext), Node ≥ 22 built-ins only at runtime (`node:fs/promises`, `node:crypto`, `node:readline`, `node:timers/promises`), Vitest. Still no runtime dependencies.

**Spec:** [`docs/superpowers/specs/2026-10-06-installer-design.md`](../specs/2026-10-06-installer-design.md) §4.1–4.2, §6.6, §7.1 (C6), §7.4, §9.3, §11.1–11.6, §11.8, §11.9. **Design decisions adopted by this plan (recorded as D56–D63 in Task 8):**

- **D56 Local MCP server = hand-rolled stdio, not the SDK.** `installer --home <home> mcp-serve` reads one JSON-RPC 2.0 message per line on stdin and writes one per line on stdout (tools only: `initialize`, `ping`, `tools/list`, `tools/call`; everything else is "method not found"). Zero dependencies, ~100 lines, the same approach as Plan 3's client (D55), and facts 2–4 show Claude Code needs nothing more. The auto action `register_tools_mcp` (starter step `preflight.tools`, right after the probe) registers it user-wide as `installer` through the profile's `mcp_register` template with `{"type":"stdio","command":<node>,"args":[<cli>,"--home",<home>,"mcp-serve"]}`. Tool names stay dotted on the wire (`memo.edit`); Claude Code shows them as `mcp__installer__memo_edit` (fact 3).
- **D57 Operational store = JSON files, not `node:sqlite`.** `node:sqlite` loads without a flag on Node 22.14 but prints an `ExperimentalWarning` on stderr at import (fact 1); the CLI's error contract is one JSON line on stderr, agents and profiles start the CLI as `node cli.js` (no flag can be added), and silencing the warning would tie the CLI to an API Node marks "might change at any time". Approval items live as `state/approvals/<id>.json` (0600 in a 0700 folder, through `confinedPath`): a new id is a hard link of a synced temp file (never replaces, so two processes never share an id), an update is temp + rename, and `<id>.claimed` is an exclusive create. `appendAudit` takes `audit/audit.lock` (exclusive create, stale-pid takeover), because the MCP server and the CLI now append concurrently. `ops.sqlite` (runs, idempotency, sessions) is revisited by Plan 7.
- **D58 Action-hash tokens.** `action_hash = "sha256:" + sha256(canonicalJson({tool, args, expected_values}))` with `expected_values: {}` for tools that declare none; `canonicalJson` is the audit's. A token is `<id>.<64 hex>` (32 random bytes), issued on approve or edit, shown to the agent only by `approvals.get`, never by `approvals.list` or the decision output. The agent presents it as the `approval_token` argument of the same tool call; it is removed before hashing. Redeeming checks: matching token (constant-time), status `approved`, not expired, the hash recomputed from this call's arguments and **live** expected values (so a value that changed since approval refuses, §9.6), the approver's role still sufficient for the level derived now; then the item is claimed (`<id>.claimed`, exclusive) and marked `used` **before** the tool runs: a crash can lose an approved action, never run it twice.
- **D59 Level derivation and the compiled floor.** `level = max(declared level (none → L2), L3 for any floor category, L3 for a written field tagged financial or protected_ground, client rule)` (§11.4). The seven floor categories are a constant in `levels.ts`. Client rules come from `config/approval-rules.json` (`{"tools":{"<tool>":"L2"}}`) and can only raise. Field tags come from a `TagSource`; the data contract that supplies it arrives in Plan 5, so production uses `NO_TAGS` and the tests use their own source. Every tool's arguments are parsed strictly, so a model-supplied `level` (or any unknown key) is refused. `approvals.*` tools are fixed at L0 and ignore rules.
- **D60 Roles.** `member` < `decision_maker`. L2 needs a member, L3 the decision maker (§11.9 defaults). Until `installer invite` (Plan 6) binds identities, the decision maker is whoever passes `--as <name>` equal to the MODE phase's `roles.decision_maker` (trimmed, any case); anyone else at the terminal is a member. An edit that raises the level raises the role needed.
- **D61 Approval surface v1 = the person's own terminal.** `installer approvals list | approve <id> | edit <id> --value '<json>' | reject <id> [--reason]`. Deciding requires stdin to be a terminal; an agent's shell has none, so its attempt is refused (exit 2) and audited as `approval.refused`. No tool can decide. Limit, stated: an agent running as the same OS user can still forge a terminal or edit the files; the real boundary is the dedicated engine OS user (D34, Plan 9) and channel identity (Plan 6). The live guide checks the TTY assumption on the real Claude Code (Test 5).
- **D62 Expiry.** An item can be decided, and its token used, until `expires_at` = request time + 24 h. Expiry is lazy: the first read after that turns `pending` or `approved` into `expired` with one `approval.expired` audit line. Reminders and escalation to the next role need channels (Plan 6). Urgent items list first (§11.7 fast path). D35's human-executed external-effect L3 flow is deferred to the plans that add such tools (5–6); v1's only L3 tool (`memo.delete`) is an internal-record action, which executes after approval.
- **D63 v1 tool set and CLI contract.** Tools are `ToolDef` entries in a registry (`name`, `description`, `fields`/`required` JSON Schema, optional `level`, `categories`, `writes`, `expected`, `parse`, `run`); Plans 5–6 add `records.*` and `channel.*` to `DEFAULT_TOOLS`. v1 ships `memo.list` (L0), `memo.add` (L1), `memo.edit` (no level → L2, expected value = current text), `memo.delete` (floor `irreversible` → L3), and the meta tools `approvals.request | list | get`. `installer tool` prints the tool's result object on stdout (exit 0); a refusal is a rule error: exit 2 with `{"error":…,"code":2}` on stderr, and over MCP a result with `isError: true`, both with the same text naming `approvals.request`.

## Global Constraints

- Everything in the Global Constraints of Plans 1–3 still applies: Node ≥ 22, strict TypeScript, ESM with `.js` suffixes, zero runtime dependencies, immutable updates, functions < 50 lines, files < 400 lines, no `console.log`, exit codes `0` OK / `1` internal / `2` usage, input or rule / `3` corrupt state or audit, spec field names verbatim, D34 confinement (every engine file through `confinedPath` under the engine home, folders `0700`, files `0600`), R4 (no secret through the agent), R9/D27 neutrality: no real-estate vocabulary in `src/`, `tests/fixtures/`, `profiles/`, `solutions/`, `INSTALL.md` (`tests/unit/neutrality.test.ts`; note that its pattern also forbids the plural of "property" unless a `:` follows, so JSON Schemas are built through `objectSchema`).
- A level is derived only from declared tool metadata, floor categories, field tags and client rules (§11.4); nothing the model sends can lower it. The floor (§11.3) is compiled into `levels.ts`; client rules only raise.
- Every tool call goes through `invokeTool`, whether it arrives over MCP or from `installer tool`; a refusal is audited before it is reported (§11.1).
- No tool decides an approval. Decisions run only from `installer approvals approve | edit | reject` with stdin attached to a terminal.
- An approval token never appears in `approvals.list`, in the decision output or in the audit; only `approvals.get` returns it, to the agent that will use it.
- `installer mcp-serve` prints nothing on stdout except JSON-RPC lines; the command returns its own exit code, never through `run()`'s `emit`.
- Tests stay offline: no network, no real keychain (`INSTALLER_KEYCHAIN=file`), no real `claude` (the fake agent and `INSTALLER_PROFILE_DIR`); the MCP server is tested by spawning `dist/cli.js mcp-serve`, never through the fake agent. Nothing reads `~/.config/installer-dev/.env`.
- New state lives in new files; `install-state.json` and its `schema: 1` do not change, so Plan 1–3 homes keep loading.

## Review Focus

1. **The same token arrives twice at once** — the agent retries, or the MCP server and `installer tool` both send it. Exactly one call runs; the other is refused with "already used". Test: Task 3 (`lets exactly one of several simultaneous calls with the same token through`), Task 5 (`lets only one of two simultaneous calls with the same token run (Review Focus 1)`).
2. **The agent approves its own request** by running `installer approvals approve <id>` from its shell. It is refused with exit 2, the attempt is audited, the item stays pending. Test: Task 5 (`refuses a decision typed where no terminal is attached (an agent's shell), audits it, and leaves the item pending`, and the refusal inside `runs the whole round: request, a person approves, the agent fetches the token and runs it once`).
3. **The action changes between approval and use** — other arguments, another tool, the memo edited by someone else meanwhile, or the agent replaying its own wording after the person edited it. Refused with "request a new approval"; the token still works for the exact approved call. Test: Task 3 (`refuses %s (hash mismatch) and keeps the token usable`), Task 4 (`refuses an approved edit when the memo changed after approval…`, `runs the person's edited version, not the agent's`).
4. **The CLI and the MCP server write the audit at the same moment.** The chain stays whole and the lock never outlives its process. Test: Task 2 (`keeps one unbroken chain when four processes append at the same time`, `takes over a lock left by a process that is gone`), Task 5 (the race test ends with `verifyAudit` ok).
5. **Something tries to lower a level** — the model passes `"level":"L0"`, a client rule says L0 for a floor tool, or a member's approval is used after the level rose to L3. The engine's level wins every time. Test: Task 1 (`never lets a client rule lower the floor or a declared level`), Task 4 (`never lets the model choose a level: an extra 'level' argument is refused`), Task 3 (`refuses a member's approval once the action has become L3`).

```ts
import { readFile } from "node:fs/promises";
import { join } from "node:path";
import { confinedPath } from "./actions.js";
import { InputError } from "./inputs.js";

/** Approval levels (spec §11.2): L0 read, L1 internal, L2 human approval, L3 floor. */
export const LEVELS = ["L0", "L1", "L2", "L3"] as const;
export type Level = (typeof LEVELS)[number];

/** Spec §11.3, compiled into the engine (D24): client rules may add to it, never remove from it. */
export const FLOOR_CATEGORIES = ["legal_notice", "money", "contract", "irreversible", "personal_data_export", "policy_change", "protected_ground"] as const;
export type FloorCategory = (typeof FLOOR_CATEGORIES)[number];

/** Field tags (spec §9.3); the data contract that assigns them arrives in Plan 5. */
export const FIELD_TAGS = ["financial", "protected_ground", "personal"] as const;
export type FieldTag = (typeof FIELD_TAGS)[number];
const FLOOR_TAGS: readonly FieldTag[] = ["financial", "protected_ground"];

/** A tool that declares no level is an ordinary write (§11.4). */
export const DEFAULT_LEVEL: Level = "L2";

export const ROLES = ["member", "decision_maker"] as const;
export type Role = (typeof ROLES)[number];

export interface FieldRef {
  readonly entity: string;
  readonly field: string;
}

/** Where field tags come from: the data contract (Plan 5). Until then nothing is tagged. */
export type TagSource = (field: FieldRef) => readonly FieldTag[];
export const NO_TAGS: TagSource = () => [];

/** Tool name → level from `config/approval-rules.json`; a rule can only raise a level (D24). */
export type ClientRules = Readonly<Record<string, Level>>;

/** What the engine knows about one call: declared tool metadata and the fields it writes, never model output. */
export interface LevelFacts {
  readonly tool: string;
  readonly level?: Level;
  readonly categories: readonly FloorCategory[];
  readonly writes: readonly FieldRef[];
}

export interface Derived {
  readonly level: Level;
  readonly reasons: readonly string[];
}

export const levelRank = (level: Level): number => LEVELS.indexOf(level);

/** Needs an approval token before it runs (§11.1). */
export const needsApproval = (level: Level): boolean => levelRank(level) >= levelRank("L2");

/** level = max(declared, field tags written, floor category, client rule) — spec §11.4. */
export function deriveLevel(facts: LevelFacts, tags: TagSource, rules: ClientRules): Derived {
  const candidates: { level: Level; reason: string }[] = [{ level: facts.level ?? DEFAULT_LEVEL, reason: facts.level ? `declared ${facts.level}` : `no declared level (default ${DEFAULT_LEVEL})` }];
  for (const category of facts.categories) candidates.push({ level: "L3", reason: `floor: ${category}` });
  for (const field of facts.writes) {
    for (const tag of tags(field).filter((item) => FLOOR_TAGS.includes(item))) candidates.push({ level: "L3", reason: `writes ${field.entity}.${field.field} (${tag})` });
  }
```

```ts
 * A new id is taken with a hard link, which never replaces an existing file, so two processes never

const RECORD_NAME = /^([1-9]\d*)\.json$/;
const NEW_BASE = "new";
const TEMP_BASE = "update";

let queue: Promise<unknown> = Promise.resolve();

/** One write at a time inside this process, so its temp file names never collide. */
function serial<T>(task: () => Promise<T>): Promise<T> {
  const run = queue.then(task, task);
  queue = run.catch(() => undefined);
  return run;
}

async function folder(home: string, dir: string): Promise<string> {
  const path = await confinedPath(home, dir);
  await mkdir(path, { recursive: true, mode: 0o700 });
  return path;
}

async function names(home: string, dir: string): Promise<string[]> {
  try {
    return await readdir(await confinedPath(home, dir));
  } catch (error) {
    if ((error as NodeJS.ErrnoException).code === "ENOENT") return [];
    throw error;
  }
}

export async function listIds(home: string, dir: string): Promise<number[]> {
  return (await names(home, dir)).flatMap((name) => RECORD_NAME.exec(name)?.[1] ?? []).map(Number).sort((a, b) => a - b);
}

export async function readRecord<T extends NumberedRecord>(home: string, dir: string, id: number, isValid: (value: unknown) => value is T): Promise<T | null> {
  const path = await confinedPath(home, join(dir, `${id}.json`));
  let text: string;
  try {
    text = await readFile(path, "utf8");
  } catch (error) {
    if ((error as NodeJS.ErrnoException).code === "ENOENT") return null;
    throw error;
  }
  let parsed: unknown;
  try {
    parsed = JSON.parse(text);
  } catch {
    parsed = undefined;
  }
  if (!isValid(parsed) || parsed.id !== id) throw new StateCorruptError(`${path} is damaged; it was not changed. Restore it from a copy, or remove it.`);
  return parsed;
}

export async function listRecords<T extends NumberedRecord>(home: string, dir: string, isValid: (value: unknown) => value is T): Promise<T[]> {
  const records: T[] = [];
  for (const id of await listIds(home, dir)) {
    const record = await readRecord(home, dir, id, isValid);
    if (record) records.push(record);
  }
  return records;
}

/** Writes `build(id)` under the next free id; retries with the following id when another process took it first. */
export function createRecord<T extends NumberedRecord>(home: string, dir: string, build: (id: number) => T): Promise<T> {
  return serial(async () => {
    const path = await folder(home, dir);
    await removeStaleTemps(path, NEW_BASE);
    const temp = join(path, `${NEW_BASE}.${process.pid}.tmp`);
    let id = ((await listIds(home, dir)).at(-1) ?? 0) + 1;
    try {
      for (;;) {
        const record = build(id);
        await writeSynced(temp, `${JSON.stringify(record, null, 2)}\n`);
        try {
          await link(temp, join(path, `${id}.json`));
          await syncDirectory(path);
          return record;
        } catch (error) {
          if ((error as NodeJS.ErrnoException).code !== "EEXIST") throw error;
          id += 1;
        }
      }
    } finally {
      await rm(temp, { force: true });
    }
  });
}

/** Atomic replace of an existing record. */
export function replaceRecord<T extends NumberedRecord>(home: string, dir: string, record: T): Promise<void> {
  return serial(async () => {
    const path = await folder(home, dir);
    await removeStaleTemps(path, TEMP_BASE);
    const temp = join(path, `${TEMP_BASE}.${process.pid}.tmp`);
    await writeSynced(temp, `${JSON.stringify(record, null, 2)}\n`);
    crashPoint("numbered:before-rename");
    await rename(temp, join(path, `${record.id}.json`));
    await syncDirectory(path);
  });
}

/** True when the record existed and is now gone. */
export function removeRecord(home: string, dir: string, id: number): Promise<boolean> {
  return serial(async () => {
    const path = await confinedPath(home, join(dir, `${id}.json`));
    try {
      await rm(path);
      return true;
    } catch (error) {
      if ((error as NodeJS.ErrnoException).code === "ENOENT") return false;
      throw error;
    }
  });
}

/** Exactly one caller, in any process, ever gets true for a given id (D58: single-use tokens). */
export async function claimOnce(home: string, dir: string, id: number): Promise<boolean> {
  const path = join(await folder(home, dir), `${id}.claimed`);
  try {
    const handle = await open(path, "wx", 0o600);
    await handle.sync();
    await handle.close();
    return true;
  } catch (error) {
    if ((error as NodeJS.ErrnoException).code === "EEXIST") return false;
    throw error;
  }
}
```

- [ ] **Step 3: Write the approvals module**

Decisions take the role into account before anything changes, and every refused decision is audited before it is reported. The token is spent with `claimOnce` and the item saved as `used` before `redeemToken` returns, so the tool runs at most once even if the process dies right after.

```ts
import { createHash, randomBytes, timingSafeEqual } from "node:crypto";
import { join } from "node:path";
import { appendAudit, canonicalJson } from "./audit.js";
import { InputError } from "./inputs.js";
import { LEVELS, ROLES, needsApproval, requiredRole, roleAtLeast, type Level, type Role } from "./levels.js";
import { claimOnce, createRecord, listRecords, readRecord, replaceRecord } from "./numbered.js";
import type { Roles } from "./types.js";

/** Approval items, one file each (D57); `<id>.claimed` marks a token as spent (D58). */
export const APPROVALS_DIR = join("state", "approvals");
/** An item, and the token issued for it, can be used for 24 hours after the request (D62). */
export const APPROVAL_TTL_MS = 24 * 60 * 60 * 1000;
export const APPROVAL_STATUSES = ["pending", "approved", "rejected", "expired", "used"] as const;
export type ApprovalStatus = (typeof APPROVAL_STATUSES)[number];
const TOKEN_PATTERN = /^([1-9]\d*)\.[0-9a-f]{64}$/;

export interface ProposedAction {
  readonly tool: string;
  readonly args: Readonly<Record<string, unknown>>;
}

/** A tool call made ready for the gate: checked arguments, live expected values, derived level, hash (D58, D59). */
export interface PreparedAction extends ProposedAction {
  readonly expected_values: Readonly<Record<string, unknown>>;
  readonly level: Level;
  readonly reasons: readonly string[];
  readonly action_hash: string;
}

export interface Decision {
  readonly decision: "approved" | "edited" | "rejected";
  readonly by: string;
  readonly role: Role;
  readonly at: string;
  readonly reason?: string;
  /** The action as requested, kept when a person edited it (a learning candidate later, §11.5). */
  readonly original?: ProposedAction;
}

/** Spec §11.5. `source.via` says which surface asked; workflows add their run and step in Plan 7. */
export interface ApprovalItem {
  readonly id: number;
  readonly source: { readonly via: "mcp" | "cli" };
  readonly level: Level;
  readonly urgent: boolean;
  readonly action: ProposedAction;
  readonly expected_values: Readonly<Record<string, unknown>>;
  readonly action_hash: string;
  readonly preview: string;
  readonly why: string;
  readonly evidence: readonly string[];
  readonly required_role: Role;
  readonly created_at: string;
  readonly expires_at: string;
  readonly status: ApprovalStatus;
  readonly decision?: Decision;
  readonly token?: string;
  readonly used_at?: string;
}

export interface ApprovalRequest {
  readonly prepared: PreparedAction;
  readonly why: string;
  readonly preview?: string;
  readonly evidence?: readonly string[];
  readonly urgent?: boolean;
  readonly via: "mcp" | "cli";
}

/** Who decides at the terminal, and with which role (D60). */
export interface Decider {
  readonly name: string;
  readonly role: Role;
}

/** The gate refused a tool call; nothing ran (§11.1). */
export class ToolRefusal extends Error {
  constructor(message: string) {
    super(message);
    this.name = "ToolRefusal";
  }
}

const sha256 = (text: string): string => createHash("sha256").update(text).digest("hex");

/** An item as the agent and the approvals list show it: everything except the token. */
export function withoutToken(item: ApprovalItem): Omit<ApprovalItem, "token"> {
  const { token: _token, ...rest } = item;
  return rest;
}

/** §11.1: `sha256(canonical_json({tool, args, expected_values}))`; a tool without expected values hashes `{}`. */
export function actionHash(tool: string, args: Readonly<Record<string, unknown>>, expectedValues: Readonly<Record<string, unknown>>): string {
  return `sha256:${sha256(canonicalJson({ tool, args, expected_values: expectedValues }))}`;
}

const isRecord = (value: unknown): value is Record<string, unknown> => typeof value === "object" && value !== null && !Array.isArray(value);

function isApprovalItem(value: unknown): value is ApprovalItem {
  if (!isRecord(value) || typeof value.id !== "number" || !isRecord(value.action) || typeof value.action.tool !== "string") return false;
  if (!(LEVELS as readonly unknown[]).includes(value.level) || !(ROLES as readonly unknown[]).includes(value.required_role)) return false;
  if (!(APPROVAL_STATUSES as readonly unknown[]).includes(value.status)) return false;
  return ["action_hash", "why", "preview", "created_at", "expires_at"].every((key) => typeof value[key] === "string");
}

const audit = (home: string, now: string, actor: "human" | "agent" | "engine", event: string, item: ApprovalItem, extra: Record<string, unknown> = {}) =>
  appendAudit(home, { ts: now, actor, event, ref: `approval:${item.id}`, payload: { id: item.id, tool: item.action.tool, level: item.level, action_hash: item.action_hash, ...extra } });

function previewOf(action: ProposedAction): string {
  const text = `${action.tool} ${canonicalJson(action.args)}`;
  return text.length > 200 ? `${text.slice(0, 199)}…` : text;
}

/** `why` is mandatory (§11.5); only L2 and L3 actions need an item. */
export async function requestApproval(home: string, request: ApprovalRequest, now: string): Promise<ApprovalItem> {
  const { prepared } = request;
  const why = request.why.trim();
  if (why === "") throw new InputError("An approval request needs a why: say in one sentence why this action is needed");
  if (!needsApproval(prepared.level)) throw new InputError(`${prepared.tool} is ${prepared.level} and needs no approval: call it directly`);
  const action = { tool: prepared.tool, args: prepared.args };
  const item = await createRecord<ApprovalItem>(home, APPROVALS_DIR, (id) => ({
    id, source: { via: request.via }, level: prepared.level, urgent: request.urgent ?? false, action,
    expected_values: prepared.expected_values, action_hash: prepared.action_hash,
    preview: request.preview?.trim() || previewOf(action), why, evidence: request.evidence ?? [],
    required_role: requiredRole(prepared.level) ?? "member", created_at: now,
    expires_at: new Date(Date.parse(now) + APPROVAL_TTL_MS).toISOString(), status: "pending",
  }));
  await audit(home, now, "agent", "approval.requested", item, { reasons: prepared.reasons });
  return item;
}

/** Lazy expiry (D62): an open item past `expires_at` becomes `expired` the first time anything reads it. */
async function expireIfDue(home: string, item: ApprovalItem, now: string): Promise<ApprovalItem> {
  const open = item.status === "pending" || item.status === "approved";
  if (!open || Date.parse(now) < Date.parse(item.expires_at)) return item;
  const expired: ApprovalItem = { ...item, status: "expired" };
  await replaceRecord(home, APPROVALS_DIR, expired);
  await audit(home, now, "engine", "approval.expired", expired);
  return expired;
}

/** Every item, expiring the overdue ones; urgent open items first (§11.7 fast path), then by id. */
export async function listApprovals(home: string, now: string): Promise<ApprovalItem[]> {
  const items: ApprovalItem[] = [];
  for (const item of await listRecords(home, APPROVALS_DIR, isApprovalItem)) items.push(await expireIfDue(home, item, now));
  const rank = (item: ApprovalItem): number => (item.urgent && item.status === "pending" ? 0 : 1);
  return items.sort((a, b) => rank(a) - rank(b) || a.id - b.id);
}

export async function getApproval(home: string, id: number, now: string): Promise<ApprovalItem> {
  const item = await readRecord(home, APPROVALS_DIR, id, isApprovalItem);
  if (!item) throw new InputError(`No approval item ${id}`);
  return expireIfDue(home, item, now);
}

/** The decision maker is whoever names the MODE phase's decision maker; anyone else at the terminal is a member (D60). */
export function deciderFor(as: string | undefined, roles: Roles | undefined): Decider {
  const name = as?.trim() || "terminal";
  const isDecisionMaker = roles !== undefined && name.toLowerCase() === roles.decision_maker.trim().toLowerCase();
  return { name, role: isDecisionMaker ? "decision_maker" : "member" };
}

/** A decision attempt that is not allowed: audited, then refused (§11.9). */
export async function refuseDecision(home: string, item: ApprovalItem, by: string, reason: string, now: string): Promise<never> {
  await audit(home, now, "human", "approval.refused", item, { by, reason });
  throw new InputError(reason);
}

/** A pending item the decider's role may decide; `needs` raises the role when an edit raises the level. */
async function openForDecision(home: string, id: number, decider: Decider, now: string, needs: Role | null = null): Promise<ApprovalItem> {
  const item = await getApproval(home, id, now);
  if (item.status !== "pending") return refuseDecision(home, item, decider.name, `Approval item ${id} is ${item.status}, not pending`, now);
  const required = needs && roleAtLeast(needs, item.required_role) ? needs : item.required_role;
  if (!roleAtLeast(decider.role, required)) {
    return refuseDecision(home, item, decider.name, `Approval item ${id} is ${item.level} and needs the decision maker: run it again with --as <decision maker's name>`, now);
  }
  return item;
}

const newToken = (id: number): string => `${id}.${randomBytes(32).toString("hex")}`;

export async function approveItem(home: string, id: number, decider: Decider, now: string): Promise<ApprovalItem> {
  const item = await openForDecision(home, id, decider, now);
  const approved: ApprovalItem = { ...item, status: "approved", token: newToken(id), decision: { decision: "approved", by: decider.name, role: decider.role, at: now } };
  await replaceRecord(home, APPROVALS_DIR, approved);
  await audit(home, now, "human", "approval.approved", approved, { by: decider.name, role: decider.role });
  return approved;
}

/** Edit = the person's version of the action, approved as edited: new hash, new level, the original kept (§11.5). */
export async function editItem(home: string, id: number, prepared: PreparedAction, decider: Decider, now: string): Promise<ApprovalItem> {
  const required = requiredRole(prepared.level) ?? "member";
  const item = await openForDecision(home, id, decider, now, required);
  if (prepared.tool !== item.action.tool) throw new InputError(`Approval item ${id} is for ${item.action.tool}; an edit can change its arguments, not the tool`);
  const edited: ApprovalItem = {
    ...item, status: "approved", token: newToken(id), level: prepared.level, required_role: required,
    action: { tool: prepared.tool, args: prepared.args }, expected_values: prepared.expected_values, action_hash: prepared.action_hash,
    decision: { decision: "edited", by: decider.name, role: decider.role, at: now, original: item.action },
  };
  await replaceRecord(home, APPROVALS_DIR, edited);
  await audit(home, now, "human", "approval.edited", edited, { by: decider.name, role: decider.role, original_hash: item.action_hash });
  return edited;
}

export async function rejectItem(home: string, id: number, decider: Decider, reason: string | undefined, now: string): Promise<ApprovalItem> {
  const item = await openForDecision(home, id, decider, now);
  const decision: Decision = { decision: "rejected", by: decider.name, role: decider.role, at: now, ...(reason?.trim() ? { reason: reason.trim() } : {}) };
  const rejected: ApprovalItem = { ...item, status: "rejected", decision };
  await replaceRecord(home, APPROVALS_DIR, rejected);
  await audit(home, now, "human", "approval.rejected", rejected, { by: decider.name, reason: decision.reason ?? null });
  return rejected;
}

function sameToken(stored: string, given: string): boolean {
  const [a, b] = [Buffer.from(stored), Buffer.from(given)];
  return a.length === b.length && timingSafeEqual(a, b);
}

const NOT_USABLE: Readonly<Record<ApprovalStatus, string>> = {
  pending: "is not approved yet",
  approved: "is approved",
  rejected: "was rejected",
  expired: "has expired; request a new approval",
  used: "was already used; request a new approval",
};

/**
 * §11.1: the token exists, is approved, not expired, approved by a sufficient role, for exactly this action hash.
 * It is spent (an exclusive claim) before the tool runs, so it can never run twice, even after a crash (D58).
 */
export async function redeemToken(home: string, token: string, prepared: PreparedAction, now: string): Promise<ApprovalItem> {
  const id = Number(TOKEN_PATTERN.exec(token)?.[1] ?? 0);
  const found = id > 0 ? await readRecord(home, APPROVALS_DIR, id, isApprovalItem) : null;
  if (!found?.token || !sameToken(found.token, token)) throw new ToolRefusal("The approval_token does not match any approval");
  const item = await expireIfDue(home, found, now);
  if (item.status !== "approved") throw new ToolRefusal(`Approval ${id} ${NOT_USABLE[item.status]}`);
  if (item.action_hash !== prepared.action_hash) throw new ToolRefusal(`This call differs from approval ${id} (the tool, its arguments or the current values changed); request a new approval`);
  const required = requiredRole(prepared.level);
  if (required && item.decision && !roleAtLeast(item.decision.role, required)) throw new ToolRefusal(`${prepared.tool} is now ${prepared.level}; approval ${id} was given by a ${item.decision.role}; request a new approval`);
  if (!(await claimOnce(home, APPROVALS_DIR, id))) throw new ToolRefusal(`Approval ${id} ${NOT_USABLE.used}`);
  const used: ApprovalItem = { ...item, status: "used", used_at: now };
  await replaceRecord(home, APPROVALS_DIR, used);
  return used;
}
```

- [ ] **Step 3: Write the registry and the gate**

`invokeTool` is the only way a tool runs. The token is taken out of the arguments before anything else, the arguments are parsed strictly, the level is derived, and an L2/L3 call without a valid token is audited and refused before `run` is ever reached.

Create `src/core/tools.ts`:

```ts
import { appendAudit } from "./audit.js";
import { ToolRefusal, actionHash, redeemToken, type PreparedAction } from "./approvals.js";
import { InputError } from "./inputs.js";
import { NO_TAGS, deriveLevel, loadClientRules, needsApproval, type ClientRules, type FieldRef, type FloorCategory, type Level, type TagSource } from "./levels.js";

export type ToolArgs = Readonly<Record<string, unknown>>;
export type ToolResult = Readonly<Record<string, unknown>>;

/** Everything a tool call needs; the same for the MCP server and `installer tool` (§7.4). */
export interface ToolContext {
  readonly home: string;
  readonly now: () => string;
  readonly via: "mcp" | "cli";
  readonly registry: ToolRegistry;
  readonly tags: TagSource;
  readonly rules: ClientRules;
}

/** One tool. Plans 5–6 add `records.*` and `channel.*` as more entries of this shape (D63). */
export interface ToolDef {
  readonly name: string;
  readonly description: string;
  /** JSON Schema of each argument; tools/list shows them as one object that takes no other keys. */
  readonly fields: Readonly<Record<string, unknown>>;
  readonly required: readonly string[];
  /** Declared level (connector `risk.actions[tool].level` later); none means L2 (§11.4). */
  readonly level?: Level;
  readonly categories?: readonly FloorCategory[];
  /** Approval bookkeeping (approvals.*): fixed L0, never raised, never gated. */
  readonly meta?: boolean;
  /** Checks and normalises the arguments; unknown keys are refused, so the model can never pass a level. */
  readonly parse: (args: ToolArgs) => ToolArgs;
  readonly writes?: (args: ToolArgs) => readonly FieldRef[];
  /** Current values the action depends on; part of the action hash, re-read when the token is used (§9.6). */
  readonly expected?: (ctx: ToolContext, args: ToolArgs) => Promise<ToolArgs>;
  readonly run: (ctx: ToolContext, args: ToolArgs) => Promise<ToolResult>;
}

export type ToolRegistry = ReadonlyMap<string, ToolDef>;

/** The argument that carries an approval token; never part of the action hash. */
export const TOKEN_ARG = "approval_token";
const TOOL_NAME = /^[a-z][a-z0-9_]*(\.[a-z][a-z0-9_]*)+$/;

export function createRegistry(defs: readonly ToolDef[]): ToolRegistry {
  return defs.reduce((registry, def) => {
    if (!TOOL_NAME.test(def.name)) throw new Error(`Tool name '${def.name}' must look like 'group.action'`);
    if (registry.has(def.name)) throw new Error(`Tool '${def.name}' is defined twice`);
    return new Map([...registry, [def.name, def]]);
  }, new Map<string, ToolDef>());
}

export function requireTool(registry: ToolRegistry, name: string): ToolDef {
  const tool = registry.get(name);
  if (!tool) throw new InputError(`Unknown tool '${name}'. Tools: ${[...registry.keys()].join(", ")}`);
  return tool;
}

export function argsOf(value: unknown): ToolArgs {
  if (typeof value !== "object" || value === null || Array.isArray(value)) throw new InputError("Tool arguments must be a JSON object");
  return value as ToolArgs;
}

export function onlyKeys(args: ToolArgs, allowed: readonly string[], tool: string): void {
  const unknown = Object.keys(args).find((key) => !allowed.includes(key));
  if (unknown !== undefined) throw new InputError(`${tool} does not take '${unknown}'${allowed.length > 0 ? `; it takes ${allowed.join(", ")}` : ""}`);
}

export const MAX_TEXT = 2000;

export function textArg(args: ToolArgs, key: string, tool: string): string {
  const value = args[key];
  if (typeof value !== "string" || value.trim() === "") throw new InputError(`${tool} needs '${key}' as non-empty text`);
  if (value.length > MAX_TEXT) throw new InputError(`${tool}: '${key}' is longer than ${MAX_TEXT} characters`);
  return value.trim();
}

export function idArg(args: ToolArgs, key: string, tool: string): number {
  const value = args[key];
  if (typeof value !== "number" || !Number.isInteger(value) || value < 1) throw new InputError(`${tool} needs '${key}' as a whole number from 1`);
  return value;
}

/** Validated arguments, live expected values and the level the engine derives — never one the model chose (D59). */
export async function prepareAction(ctx: ToolContext, tool: ToolDef, args: ToolArgs): Promise<PreparedAction> {
  const parsed = tool.parse(args);
  const expected = tool.expected ? await tool.expected(ctx, parsed) : {};
  const facts = { tool: tool.name, categories: tool.categories ?? [], writes: tool.writes?.(parsed) ?? [], ...(tool.level ? { level: tool.level } : {}) };
  const { level, reasons } = tool.meta ? { level: "L0" as const, reasons: ["approval bookkeeping (fixed L0)"] } : deriveLevel(facts, ctx.tags, ctx.rules);
  return { tool: tool.name, args: parsed, expected_values: expected, level, reasons, action_hash: actionHash(tool.name, parsed, expected) };
}

const toolAudit = (ctx: ToolContext, event: string, prepared: PreparedAction, extra: Record<string, unknown>) =>
  appendAudit(ctx.home, { ts: ctx.now(), actor: "agent", event, ref: prepared.tool, payload: { tool: prepared.tool, level: prepared.level, action_hash: prepared.action_hash, via: ctx.via, ...extra } });

/** Every refusal is audited, then thrown (§11.1). */
async function refuse(ctx: ToolContext, prepared: PreparedAction, reason: string): Promise<never> {
  await toolAudit(ctx, "tool.refused", prepared, { reason });
  throw new ToolRefusal(reason);
}

function approvalNeeded(prepared: PreparedAction): string {
  const request = JSON.stringify({ tool: prepared.tool, args: prepared.args, why: "<why this is needed>" });
  return `${prepared.tool} is ${prepared.level} (${prepared.reasons.join("; ")}): a person must approve it first. Call approvals.request with ${request}, `
    + `ask the person to approve it in their own terminal, then call approvals.get and call ${prepared.tool} again with the same arguments plus "${TOKEN_ARG}"`;
}

/** L0 runs silently; L1 and above are logged (§11.2); a failure after a spent token is logged too. */
async function runLogged(ctx: ToolContext, tool: ToolDef, prepared: PreparedAction, approval: number | null): Promise<ToolResult> {
  let result: ToolResult;
  try {
    result = await tool.run(ctx, prepared.args);
  } catch (error) {
    if (approval !== null) await toolAudit(ctx, "tool.failed", prepared, { approval, reason: (error as Error).message });
    throw error;
  }
  if (prepared.level !== "L0") await toolAudit(ctx, "tool.executed", prepared, { approval });
  return result;
}

/** The gate (§11.1): L2 and L3 need a token for exactly this action; the same path for MCP and the CLI. */
export async function invokeTool(ctx: ToolContext, name: string, rawArgs: unknown): Promise<ToolResult> {
  const tool = requireTool(ctx.registry, name);
  const { [TOKEN_ARG]: token, ...args } = argsOf(rawArgs);
  if (tool.meta && token !== undefined) throw new InputError(`${name} takes no ${TOKEN_ARG}`);
  const prepared = await prepareAction(ctx, tool, args);
  if (!needsApproval(prepared.level)) return runLogged(ctx, tool, prepared, null);
  if (typeof token !== "string") return refuse(ctx, prepared, approvalNeeded(prepared));
  let approval: number;
  try {
    approval = (await redeemToken(ctx.home, token, prepared, ctx.now())).id;
  } catch (error) {
    if (error instanceof ToolRefusal) return refuse(ctx, prepared, error.message);
    throw error;
  }
  return runLogged(ctx, tool, prepared, approval);
}

export function objectSchema(fields: Readonly<Record<string, unknown>>, required: readonly string[]): Readonly<Record<string, unknown>> {
  return { type: "object", properties: fields, required, additionalProperties: false };
}

const TOKEN_FIELD = { type: "string", description: "Token from approvals.get once a person approved this exact call" };

/** What tools/list shows: gated tools take an optional approval_token; meta tools do not. */
export function describeTools(registry: ToolRegistry): readonly { name: string; description: string; inputSchema: Readonly<Record<string, unknown>> }[] {
  return [...registry.values()].map((tool) => ({
    name: tool.name,
    description: tool.description,
    inputSchema: objectSchema(tool.meta ? tool.fields : { ...tool.fields, [TOKEN_ARG]: TOKEN_FIELD }, tool.required),
  }));
}

export async function toolContext(home: string, via: "mcp" | "cli", registry: ToolRegistry, now: () => string = () => new Date().toISOString()): Promise<ToolContext> {
  return { home, now, via, registry, tags: NO_TAGS, rules: await loadClientRules(home) };
}
```

```ts
const USAGE = "approvals needs one of: list, approve <id>, edit <id> --value '<json arguments>', reject <id> [--reason <text>]";

function parseId(text: string | undefined): number {
  if (!text || !/^[1-9]\d*$/.test(text)) throw new InputError(`${USAGE}; <id> is the item number, for example 7`);
  return Number(text);
}

function editedArgs(value: string | undefined): unknown {
  if (value === undefined) throw new InputError("edit needs --value '<json arguments>': the arguments as you want them, for example --value '{\"id\":1,\"text\":\"…\"}'");
  try {
    return JSON.parse(value);
  } catch {
    throw new InputError("--value must be the tool's arguments as JSON");
  }
}

/** What the person sees after deciding; the token stays with the item for the agent's approvals.get. */
function decided(item: ApprovalItem): unknown {
  const next = item.status === "approved" ? `Tell the agent that item ${item.id} is approved: it fetches the token with approvals.get and runs exactly this action` : undefined;
  return { ...withoutToken(item), ...(next ? { next } : {}) };
}

async function decide(home: string, roles: Roles | undefined, command: ApprovalsCommand, now: () => string): Promise<ApprovalItem> {
  const id = parseId(command.id);
  const decider = deciderFor(command.as, roles);
  if (!command.interactive) {
    const reason = `Approvals are decided by a person in their own terminal, not by the agent: open a terminal and run 'installer approvals ${command.sub} ${id}' there`;
    return refuseDecision(home, await getApproval(home, id, now()), decider.name, reason, now());
  }
  if (command.sub === "approve") return approveItem(home, id, decider, now());
  if (command.sub === "reject") return rejectItem(home, id, decider, command.reason, now());
  const item = await getApproval(home, id, now());
  const ctx = await toolContext(home, "cli", DEFAULT_TOOLS, now);
  const prepared = await prepareAction(ctx, requireTool(DEFAULT_TOOLS, item.action.tool), argsOf(editedArgs(command.value)));
  return editItem(home, id, prepared, decider, now());
}

export async function approvalsCommand(home: string, roles: Roles | undefined, command: ApprovalsCommand, now: () => string): Promise<unknown> {
  if (command.sub === "list") return { items: (await listApprovals(home, now())).map(withoutToken) };
  if (!DECISIONS.includes(command.sub ?? "")) throw new InputError(USAGE);
  return decided(await decide(home, roles, command, now));
}
```

```ts
import { spawn } from "node:child_process";
import { resolve } from "node:path";
import { createInterface } from "node:readline";

export interface StdioMcp {
  /** Sends a request and resolves with the answer that carries its id; rejects if the server exits first. */
  readonly request: (method: string, params?: unknown, id?: string | number) => Promise<Record<string, unknown>>;
  readonly notify: (method: string, params?: unknown) => void;
  /** Every line the server printed on stdout so far. */
  readonly lines: string[];
  /** Closes stdin and resolves with the exit code. */
  readonly close: () => Promise<number | null>;
}

interface Waiting {
  readonly done: (message: Record<string, unknown>) => void;
  readonly fail: (error: Error) => void;
}

/** Spawns `installer --home <home> mcp-serve` the way an agent's MCP client does. */
export function startStdioMcp(home: string): StdioMcp {
  const child = spawn(process.execPath, [resolve("dist/cli.js"), "--home", home, "mcp-serve"], { stdio: ["pipe", "pipe", "inherit"] });
  child.stdin.on("error", () => undefined);
  const lines: string[] = [];
  const waiting = new Map<string | number, Waiting>();
  const exited = new Promise<number | null>((done) => child.once("exit", done));
  void exited.then((code) => waiting.forEach((entry) => entry.fail(new Error(`installer mcp-serve exited with ${code} before answering`))));
  createInterface({ input: child.stdout }).on("line", (line) => {
    lines.push(line);
    const message = JSON.parse(line) as Record<string, unknown>;
    waiting.get(message.id as string | number)?.done(message);
  });
  let next = 1;
  const write = (message: Record<string, unknown>) => child.stdin.write(`${JSON.stringify({ jsonrpc: "2.0", ...message })}\n`);
  return {
    request: (method, params, id = next++) =>
      new Promise((done, fail) => {
        waiting.set(id, { done, fail });
        write({ id, method, ...(params === undefined ? {} : { params }) });
      }),
    notify: (method, params) => write({ method, ...(params === undefined ? {} : { params }) }),
    lines,
    close: () => {
      child.stdin.end();
      return exited;
    },
  };
}
```

```ts
import { createInterface } from "node:readline";
import type { Readable, Writable } from "node:stream";
import { ToolRefusal } from "./approvals.js";
import { AuditCorruptError } from "./audit.js";
import { ActionFailure } from "./failure.js";
import { InputError } from "./inputs.js";
import { StateCorruptError } from "./state.js";

/**
 * The local MCP server (D56): newline-delimited JSON-RPC 2.0 on stdin/stdout, hand-rolled, tools only.
 * Verified against Claude Code 2.1.294: it first sends `server/discover` (answered "method not found",
 * which it accepts), then `initialize` asking 2025-11-25, and accepts 2025-06-18 in the answer.
 */
export const SERVER_INFO = { name: "installer", version: "0.1.0" };
export const PROTOCOL_VERSIONS = ["2025-06-18", "2025-03-26", "2024-11-05"] as const;
export const SERVER_INSTRUCTIONS =
  "Tools at level L2 or L3 refuse to run until a person approves that exact call: call approvals.request with the tool, its arguments and why, " +
  "ask the person to approve it in their own terminal, then call approvals.get and repeat the call with the same arguments plus approval_token. " +
  "Never ask the person for a token and never try to approve anything yourself.";
const RPC = { PARSE_ERROR: -32700, INVALID_REQUEST: -32600, METHOD_NOT_FOUND: -32601, INVALID_PARAMS: -32602 } as const;

export interface ToolDescription {
  readonly name: string;
  readonly description: string;
  readonly inputSchema: Readonly<Record<string, unknown>>;
}

export interface ServerHandlers {
  readonly list: () => readonly ToolDescription[];
  readonly call: (name: string, args: unknown) => Promise<Readonly<Record<string, unknown>>>;
}

type Id = string | number | null;
type Message = Readonly<Record<string, unknown>>;
const isRecord = (value: unknown): value is Message => typeof value === "object" && value !== null && !Array.isArray(value);

const answer = (id: Id, result: unknown): Message => ({ jsonrpc: "2.0", id, result });
const failure = (id: Id, code: number, message: string): Message => ({ jsonrpc: "2.0", id, error: { code, message } });

/** Errors the agent or a person can act on are tool results the model reads; anything else is an internal error. */
const ACTIONABLE = [InputError, ToolRefusal, ActionFailure, StateCorruptError, AuditCorruptError];

function toolError(error: unknown): Message {
  const message = error instanceof Error ? error.message : String(error);
  const text = ACTIONABLE.some((kind) => error instanceof kind) ? message : `Internal error: ${message}`;
  return { content: [{ type: "text", text }], isError: true };
}

function negotiate(params: unknown): string {
  const asked = isRecord(params) ? params.protocolVersion : undefined;
  return (PROTOCOL_VERSIONS as readonly unknown[]).includes(asked) ? (asked as string) : PROTOCOL_VERSIONS[0];
}

async function callTool(handlers: ServerHandlers, id: Id, params: unknown): Promise<Message> {
  const name = isRecord(params) ? params.name : undefined;
  if (typeof name !== "string") return failure(id, RPC.INVALID_PARAMS, "tools/call needs params.name");
  if (!handlers.list().some((tool) => tool.name === name)) return failure(id, RPC.INVALID_PARAMS, `Unknown tool: ${name}`);
  try {
    const value = await handlers.call(name, (isRecord(params) ? params.arguments : undefined) ?? {});
    return answer(id, { content: [{ type: "text", text: JSON.stringify(value) }], structuredContent: value });
  } catch (error) {
    return answer(id, toolError(error));
  }
}

async function dispatch(handlers: ServerHandlers, id: Id, method: string, params: unknown): Promise<Message> {
  if (method === "initialize") {
    return answer(id, { protocolVersion: negotiate(params), capabilities: { tools: {} }, serverInfo: SERVER_INFO, instructions: SERVER_INSTRUCTIONS });
  }
  if (method === "ping") return answer(id, {});
  if (method === "tools/list") return answer(id, { tools: handlers.list() });
  if (method === "tools/call") return callTool(handlers, id, params);
  return failure(id, RPC.METHOD_NOT_FOUND, `Method not found: ${method}`);
}

/** One line in, at most one line out. Notifications and the client's own responses get no answer. */
export async function handleLine(handlers: ServerHandlers, line: string): Promise<Message | null> {
  let message: unknown;
  try {
    message = JSON.parse(line);
  } catch {
    return failure(null, RPC.PARSE_ERROR, "Parse error");
  }
  if (!isRecord(message) || message.jsonrpc !== "2.0") return failure(null, RPC.INVALID_REQUEST, "Expected one JSON-RPC 2.0 message per line");
  const { id, method } = message;
  if (id === undefined || typeof method !== "string") return null;
  if (typeof id !== "string" && typeof id !== "number") return failure(null, RPC.INVALID_REQUEST, "The id must be a string or a number");
  return dispatch(handlers, id, method, message.params);
}

/** Serves until the client closes stdin; requests are handled one at a time, in order. */
export function serveStdio(handlers: ServerHandlers, input: Readable, output: Writable): Promise<void> {
  const lines = createInterface({ input, crlfDelay: Infinity });
  let queue: Promise<void> = Promise.resolve();
  lines.on("line", (line) => {
    if (line.trim() === "") return;
    queue = queue.then(async () => {
      const reply = await handleLine(handlers, line);
      if (reply) output.write(`${JSON.stringify(reply)}\n`);
    });
  });
  return new Promise((done) => {
    lines.once("close", () => void queue.then(done));
  });
}
```
